# metrogon
A unique take on the metronome using polygons as the visual reference.
new metronome idea - MetraNome/Gon or MetroGON because of the shapes :) 
- metronome uses gemometric shapes to show time: 
- square is 4 beats (or 4/4)
- triangle is 3 or (3/4
- pentagon is 5 or 5/4
and so on!

Note: the points of the shapes are the COUNT. For instance with the square: 1, 2, 3, 4. The corners of the square are the dotted counted beats and should be visible.
Same for other shapes. 
- speed BPM slider.
- distinct sounds for the ONE beat. But can be changes. basic drum sounds (bass drum, closed hi-hat, snare and cow bell, side stick, agogo bell). Should be a config menu to assign, but initial set up is cow bell for 1, and rest of beats (Like 2, 3, 4) are side stick.
